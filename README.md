# Wine Atlas

Aplicação web mobile-first para descobrir regiões vinícolas e castas próximas,
consultar uma enciclopédia de castas e aprender boas práticas de vinho.

## Desenvolvimento

```bash
npm install
npm run dev
```

## Validação

```bash
npm run check
npm run build
```

O Wine Atlas é totalmente client-side. A localização é processada no browser e
os favoritos, idioma, tema e consentimento de analytics ficam no `localStorage`.
